## 🧠 Central Shared Memory & Coordination
All agent sessions, conversation transcripts, task histories, and architectural memories are stored centrally in:
📁 **`C:\Users\Admin\Desktop\projects\memory of agent`**

### Key Files in the Memory Folder:
1. **`PROJECT_MEMORY.md`**: Architectural decisions, ongoing tasks, and milestone records.
   * Path: `C:\Users\Admin\Desktop\projects\memory of agent\PROJECT_MEMORY.md`
   * *Instruction:* Read this file if you need background on what other agents have recently implemented.
2. **`agent_tasks.csv`**: Master Excel tasks sheet tracking all completed and in-progress tasks across all IDE and CLI sessions.
3. **`multi_agent_control.csv`**: Active Git branches, worktree folders, and collision detection.

## 🛡️ Multi-Agent Concurrency & Branch Isolation
* If working on this main repository, ensure you are on the intended branch (`main`).
* If working on a dedicated agent branch (e.g. `agent/antigravity` or `agent/claude`), work in your assigned worktree folder to avoid collisions.
* When completing major milestones, update `C:\Users\Admin\Desktop\projects\memory of agent\PROJECT_MEMORY.md` with your changes.
