Day 7 Conditional Rendering: Guard Clauses, Ternaries & The Falsy Zero (0 && ) Pitfall Stage 1: Mental Model Grounding
Month 1 • Block 2 • 4 Quests
🎯 Spoken Goal & Invariant:
Goal: Master conditional UI rendering: Learn when to use early return guard clauses, ternary operators, and understand why the common `count && ` pattern leaks the number '0' onto user screens.
Invariant: In JavaScript, `0 && ` evaluates to `0`, NOT `false`. Because React renders numbers directly to the DOM, an unread count of 0 renders an unwanted '0' on the webpage. Always use boolean coercion `Boolean(count)` or `count > 0`.
⚠️ Failure Mode & tryIt Bug:
Failure: Writing `{unreadCount && }` displays an orphaned '0' on the user's navbar when there are no unread messages.
tryIt Friction: Audit a component containing multiple logical AND (`&&`) checks, replace falsy numeric traps with explicit comparisons (`items.length > 0 ? ... : null`), and verify clean DOM output.
