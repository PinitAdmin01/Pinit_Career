🧩 Situational Diagnostic Puzzle: "A subclass constructor performs: "this.interestRate = 0.05; super(name);". javac throws "call to super must be first statement in constructor". Why does Java enforce this strict rule?"
Correct: Option B) The parent class memory layout must be initialized before the child class can safely execute any code or reference parent fields. • Debrief: Parent class fields must be constructed before child code executes. Placing super() anywhere other than line 1 risks accessing uninitialized parent state.
