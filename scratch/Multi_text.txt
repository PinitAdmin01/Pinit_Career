   2. The Individual Course (Quest) Workflow 
 
Every quest/course in PinIT follows a closed socratic learning loop. The browser sandbox handles compilation locally 
to reduce server cost to zero: 
 
```mermaid 
sequenceDiagram 
    autonumber 
--- PAGE 8 ---
    actor Student 
    participant Hub as Quests Hub (/quests) 
    participant Workspace as Editor Workspace (/quests/[id]) 
    participant Sandbox as Local WASM Sandbox 
    participant AI as AI Socratic Mentor 
    participant DB as Supabase/Local Storage 
 
    Student->>Hub: Click "Start Quest" 
    Hub->>Workspace: Route to Quest Workspace (Deduct 5 Pins) 
    Workspace->>Student: Render objective checklist (Left) & seed code (Right) 
    Student->>Workspace: Write code or input design parameters 
    Student->>Workspace: Click "Run Tests" 
    Workspace->>Sandbox: Execute tests inside browser virtual environment 
    alt Tests Fail 
        Sandbox-->>Workspace: Return execution logs & assert errors 
        Workspace-->>Student: Display compilation errors & suggest hints 
    else Tests Pass 
        Sandbox-->>Workspace: Return 100% success signature 
        Workspace->>AI: Fetch socratic feedback tip 
        AI-->>Workspace: Return conceptual review tip 
        Workspace->>Student: Display success panel & AI feedback 
        Student->>Workspace: Click "Complete Quest" 
        Workspace->>DB: Write quest completion state, add +30 XP , award +10 Pins 
        DB-->>Hub: Unlock next sequential quest in timeline 
    end 
```
