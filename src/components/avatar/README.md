# AI Mentor Avatar Components (`src/components/avatar/`)

---

## 1. What It Is
This folder handles the interactive AI Mentor widgets, conversational prompts, and WebRTC photorealistic digital human avatars.

## 2. Why It Exists (Non-Negotiable Purpose)
*   **Rule Met**: *Collect Human Signal* & *Improve Human Potential*
*   **Purpose**:
    - **Speech Capture**: Records the student's vocal responses during verbal assessments to analyze clarity, fluency, and structures.
    - **Interactive Coaching**: Serves as the conversational interface for the AI Twin memory queries and custom skill-training recommendations.
