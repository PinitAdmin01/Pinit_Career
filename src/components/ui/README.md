# Global Shell & HUD Widgets (`src/components/ui/`)

---

## 1. What It Is
This folder houses the main AppShell sidebar navigation, top bar telemetry metrics, and dashboard checklists (such as `WhatToDoToday` and `NextStepCard`).

## 2. Why It Exists (Non-Negotiable Purpose)
*   **Rule Met**: *Improve Human Potential*
*   **Purpose**:
    - **Visual Evolution HUD**: Displays current Levels, Potential Scores, and DNA streaking progress to drive student motivation.
    - **Personalized Recommendations**: Derives and renders 3 immediate, high-priority actions based on the student's profile context to keep their growth trajectory moving forward.
