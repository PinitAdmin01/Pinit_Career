# Career Trajectory Components (`src/components/career/`)

---

## 1. What It Is
This folder contains the SDE, BSc, and Arts trajectory cards, skill Tag lists, and the resume parser layouts.

## 2. Why It Exists (Non-Negotiable Purpose)
*   **Rule Met**: *Improve Human Potential*
*   **Purpose**: Maps out the career objectives. It displays target roles and required skills, allowing the Quest Agent to generate personalized study modules that bridge the gap between their current capabilities and recruiter placements.
