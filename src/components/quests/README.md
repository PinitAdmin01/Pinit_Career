# Quest Workspace Components (`src/components/quests/`)

---

## 1. What It Is
This folder houses the split-screen quest workspace, Monaco Editor wrapper, and unit test compilation scripts.

## 2. Why It Exists (Non-Negotiable Purpose)
*   **Rule Met**: *Improve Human Potential*
*   **Purpose**: Validates technical skills. It provides an isolated WebAssembly sandbox where students write code, debug scripts, and compile solutions locally against unit tests to increase their execution and problem-solving metrics on the Human Graph.
